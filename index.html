Google Sheets Integration

Paste this formula into any cell to import the full dataset:

=IMPORTDATA("https://raw.githubusercontent.com/spofas/cgeckopricedata_claude/main/data/prices.csv")

The data refreshes automatically — Google Sheets will pick up updates within ~1 hour.

Excel Integration

Option 1: Download the CSV and open it directly.

Option 2: Use Power Query for auto-refresh — go to Data → From Web and enter:

https://raw.githubusercontent.com/spofas/cgeckopricedata_claude/main/data/prices.csv

Run It Yourself

git clone https://github.com/spofas/cgeckopricedata_claude.git cd cgeckopricedata_claude pip install -r requirements.txt python fetch_prices.py

Optionally set COINGECKO_API_KEY env var for faster fetching (free key from coingecko.com).

Data sourced from CoinGecko. Updated every 2 hours via GitHub Actions.
